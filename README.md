# HADI Dev Studio

Private AI-assisted software factory for Hadi.

## Goal

Use ChatGPT as the reasoning/orchestration layer and GitHub + Railway + browser testing as the execution surface for real software projects.

## Supported project types

- Websites & landing pages
- Telegram bots
- Admin panels
- VPN subscription panels
- Mobile apps
- Games
- AI systems
- Custom software

## Current phase

Foundation / Phase 01 — approximately 10%.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Health check

`GET /api/health`

## Agent registry
