# AJENT / HADI Dev Studio

## Product

A private AI-assisted software factory controlled from ChatGPT.

## Objective

Allow Hadi to bring client projects into ChatGPT and run a structured internal team for requirements, architecture, UI/UX, implementation, testing, review and deployment.

## Supported delivery types

- Website / landing page
- Telegram bot
- Admin panel
- VPN subscription panel
- Mobile app
- Game
- AI system
- Custom software

## Core integrations

- ChatGPT: reasoning and orchestration
- GitHub: code + durable project memory
- Railway: deployment and runtime
- Browser testing: live UI validation

## Phase 01 acceptance criteria

- GitHub repository initialized
- Deployable web foundation
- Agent registry
- Project type registry
- Health endpoint
- Architecture and roadmap docs
- Private ChatGPT plugin workflow
